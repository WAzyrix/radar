# Radar

Site perso qui regroupe les actus qui m'intéressent : animés/mangas, films/séries, cybersécurité et actu générale.

> 🚧 En construction : maquette visuelle en cours de validation.

## Lancer en local

```bash
python3 -m http.server 8000
```

Puis ouvrir <http://localhost:8000>.

## Maquette

Le dossier `maquette/` contient la proposition visuelle (accueil + fiche animé), branchée en direct sur l'API AniList.
En local : <http://localhost:8000/maquette/>
